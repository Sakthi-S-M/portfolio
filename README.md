# Sakthi S M — Portfolio

Personal portfolio website: front-end and security projects, hackathon and CTF wins, teaching, and contact details.

**Live site:** https://sakthi-s-m.github.io/portfolio/

## Built with
- Plain HTML, CSS and a little JavaScript (no build step)
- Google Fonts: Bricolage Grotesque, Instrument Sans, JetBrains Mono
- Light and dark themes that follow your system setting
- Load and scroll animations, sticky section nav and an animated network backdrop (all turned off for visitors who prefer reduced motion)

## Run locally
Open `index.html` in any browser.
